## 关键教训
- **Bash 工具的沙盒代理会卡死 EAS 上传**：eas 流量被导入 127.0.0.1:59732（sandbox-cli），25 分钟零进展。改用 `dangerouslyDisableSandbox` 直连后 72 秒上传完成。以后 eas/npm 发布类命令一律绕过沙盒。
- 本机代理端口归属可用 `Get-NetTCPConnection -OwningProcess` + 进程名排查。
- PowerShell 工具禁用 `Add-Type`（编译代码）与 COM 实例化；GUI 自动化改用 **Python ctypes + Win32**（SendInput / 剪贴板 / PrintWindow 截图）。
- ctypes 调 user32/kernel32 必须显式声明 `restype/argtypes`（64 位句柄截断导致 GlobalLock 空指针）。
- **CF_HDROP 的 DROPFILES 头**：pFiles=20、fWide=1，写成全零则微信粘贴无效。
- 截图方案：`PrintWindow(PW_RENDERFULLCONTENT)` + GetDIBits + 手写 PNG 编码（stdlib zlib/struct），不抢焦点。脚本在 `%TEMP%/musicapp-expo/`（win_shot.py / wechat_send.py）。
- eas build:view 在管道中可能长时间挂起（python subprocess 加 timeout 240s 仍可能卡），轮询不如手动循环查询可靠。
